# Changelog

## v7.22 - First public release

- Four modes: steering wheel, flight yoke (Realistic and Arcade styles), motorcycle and gamepad
- Automatic Wi-Fi discovery, manual IP entry, and USB connection through adb
- Movable and resizable on-screen controls, saved layouts, and button mapping to Xbox buttons or keyboard keys
- Per-mode settings with an explanation next to each setting
- Gamepad mode with optional gyroscope or touchpad aiming and a low-latency Wi-Fi channel
- Optional pause on disconnect (Start button or Esc key)
- Arabic and English interface
- Optional Islamic dhikr reminder notifications (Arabic interface only, off by default)
